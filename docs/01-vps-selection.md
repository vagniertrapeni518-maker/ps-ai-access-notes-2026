## 三、新手必守的 3 条安全边界

1. **国内外云服务彻底隔离**：已有国内云主机（如阿里云/腾讯云等）继续仅托管合规国内项目，严禁用于代理用途；账号、密码与配置完全隔离。
2. **外币信用卡防盗刷**：海外网站常见无短信验证码直接凭卡号+有效期+CVV 扣款。实体卡寄到前全锁；日常长期锁死境内/境外线下刷卡；**境外无卡交易**做到“付年费前开、付完即锁”，若有月付订阅则设低消费上限，并开启自动购汇还款。
3. **绝不泄露真实凭证**：真实 IP、端口、面板路径、UUID、Reality 私钥/公钥与 ShortId 仅保存于本地密码管理器，不粘贴至陌生“在线订阅转换”网站，不提交至公开 Git 仓库。
